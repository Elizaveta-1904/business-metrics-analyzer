Business Metrics Analyzer
 Название проекта
Business Metrics Analyzer — учебное приложение для анализа бизнес-метрик.
Бизнес-задача
Приложение предназначено для анализа основных бизнес-показателей компании.
В рамках проекта выполняется расчёт бизнес-метрик, в том числе показателя рентабельности. Результаты расчёта позволяют оценить соотношение выручки и затрат.

Используемые технологии

- Python
- pandas
- matplotlib
- Git
- GitHub


Инструкция по запуску
1. Клонировать репозиторий.
2. Установить зависимости:
   pip install -r requirements.txt
3. Запустить приложение:
   python main.py
