# Бизнес-требования к приложению Business Metrics Analyzer

## 1. Назначение приложения

Приложение Business Metrics Analyzer предназначено для учебного анализа бизнес-метрик.

## 2. Бизнес-задача

Приложение предназначено для расчёта и анализа основных бизнес-показателей компании.

Одним из реализованных показателей является рентабельность, которая рассчитывается на основе выручки и затрат.

## 3. Основные требования

Приложение должно:

- принимать исходные значения бизнес-показателей;
- выполнять расчёт рентабельности;
- выводить результат расчёта;
- использовать Python для реализации расчётов;
- обеспечивать возможность дальнейшего добавления других бизнес-метрик.

## 4. Расчёт рентабельности

Рентабельность рассчитывается по формуле:

Рентабельность = (Выручка - Затраты) / Выручка × 100%

При нулевой выручке результат расчёта должен быть равен 0.

## 5. Используемые технологии

Для разработки используются:

- Python;
- pandas;
- matplotlib;
- Git;
- GitHub.

## 6. Результат работы

Результатом работы приложения является рассчитанное значение бизнес-метрики, которое может использоваться для анализа деятельности компании.
