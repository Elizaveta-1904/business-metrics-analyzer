# User Stories — Business Metrics Analyzer

## US-01. Просмотр дашборда KPI

**Как** коммерческий директор,
**я хочу** видеть дашборд с ключевыми KPI на главной странице,
**чтобы** оперативно оценивать состояние продаж без ручных отчётов.

**Приоритет:** Must have
**Оценка:** 5 Story Points
**Спринт:** 1

**Критерии приёмки:**

- **AC-01.1** Given: пользователь авторизован, When: открывает главную страницу, Then: отображается дашборд с KPI.
- **AC-01.2** Given: данные загружены, When: выбирает период, Then: KPI обновляются за 3 секунды.

**Приоритет:** Must have
**Оценка:** 8 Story Points
**Спринт:** 1

**Критерии приёмки:**

## US-03. Формирование отчёта

**Как** аналитик,
**я хочу** формировать отчёт по продажам за период,
**чтобы** анализировать динамику продаж.

**Приоритет:** Must have
**Оценка:** 5 Story Points
**Спринт:** 1

**Критерии приёмки:**

- **AC-03.1** Given: данные загружены, When: пользователь выбирает период, Then: система формирует отчёт.
- **AC-03.2** Given: данных нет, When: пользователь формирует отчёт, Then: выводится сообщение «Нет данных».

## US-07. Уведомления о KPI

**Приоритет:** Could have
**Оценка:** 3 Story Points
**Спринт:** 3

**Критерии приёмки:**

- **AC-07.1** Given: порог KPI задан, When: показатель выходит за пределы, Then: формируется уведомление.
